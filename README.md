## 📖 选购指南

### 购买前须知

| 建议 | 说明 |
|------|------|
| 🆕 **新手建议** | 先购买普通机场月付或短周期套餐，避免一次性购买过长周期 |
| 📡 **线路选择** | 中转/专线通常优于普通直连，但体验取决于地区和运营商 |
| 🔄 **备用机场** | 经常使用的话，一定要准备备用机场，不要把所有需求押在一个机场上 |
| 🎯 **特殊需求** | AI/Emby观影/新疆地区/无限设备/无限流量可选择特色机场 |
| 🌱 **成长机场** | 经验丰富的用户可考虑机龄短的成长机场，价格低速度快但风险高 |

### 常见问题

<details>
<summary><b>直连、中转和专线怎么选？</b></summary>

更推荐中转机场，带宽更充足；专线优势是不过墙、延迟更低。
</details>

<details>
<summary><b>判断机场好坏重点看什么？</b></summary>

**带宽和稳定性最重要**，其次看节点数量、线路质量和客服响应速度。
</details>

<details>
<summary><b>协议需要纠结吗？</b></summary>

中转机场协议不是最重要的，中转机器稳定性和带宽更关键。
</details>

<details>
<summary><b>排名能否照着买？</b></summary>

不同地区、运营商、时段体验有差异，建议先购买短周期套餐测试。
</details>
