## 快速开始（3 分钟版）

### 第一步：选一个机场
在主仓库的五大系列中，新手建议从**普通系列**或**性价比系列**里选一个，先买月付或短周期套餐测试。

### 第二步：下载客户端
根据你的设备选择客户端（详见 [客户端配置教程](02-客户端配置教程.md)）：
- **Windows**：Clash Verge Rev
- **macOS**：ClashX Meta / Clash Verge Rev
- **Android**：Clash Meta for Android / FlClash
- **iOS**：Shadowrocket / Stash（需非国区 Apple ID）
- **路由器**：OpenClash / PassWall2

### 第三步：导入订阅
1. 在机场官网注册账号
2. 复制「订阅链接」
3. 打开客户端 → 导入订阅 → 粘贴链接 → 更新配置
4. 选择节点，开启代理

### 第四步：验证
打开 [ipinfo.io](https://ipinfo.io) 查看 IP 是否已变更，或访问 Google 测试连通性。
