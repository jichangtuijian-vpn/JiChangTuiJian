# 🔍 机场选购深度指南

> 不只看排名，教你建立自己的判断标准。

---

## 核心结论（先看这里）

**判断机场好坏，最重要的两个指标：带宽 + 稳定性。**

其他都是次要的。一个带宽充足、常年稳定的机场，比一个节点数量多但经常挂的机场强得多。

---

## 一、五种线路类型对比

| 线路类型 | 原理 | 优点 | 缺点 | 适合场景 |
|----------|------|------|------|----------|
| **直连** | 流量直接出境 | 便宜 | 晚高峰拥堵、不稳定 | 轻度使用 |
| **中转** | 先到国内中转机再到境外 | 带宽足、较稳定 | 多一跳略微延迟 | 大多数人日常使用 |
| **IEPL 专线** | 运营商以太网专线 | 稳定、低延迟、不过墙 | 贵、流量少 | 追求稳定 |
| **IPLC 专线** | 国际专线 | 极稳定、原生 IP | 最贵 | 金融/AI/高要求 |
| **家宽/住宅** | 家庭宽带出口 IP | IP 干净、解锁好 | 数量少、价格高 | 流媒体/AI/银行 |

### 怎么选？
- **日常通用** → 中转机场（性价比最高）
- **晚高峰也要稳** → 专线机场
- **看流媒体/用 AI/银行** → 家宽节点
- **预算有限** → 性价比系列，但要有心理准备

## 二、六大选购维度

### 1. 稳定性 ⭐⭐⭐⭐⭐
**最重要。** 看方法：
- 观察几天，不同时段测试
- 看机场的公告群，是否经常"维护"
- 问老用户口碑

### 2. 带宽 ⭐⭐⭐⭐⭐
晚高峰的实际速度才是真实带宽。标称 1Gbps 但晚高峰只有 5Mbps 的机场要警惕。

### 3. 延迟 ⭐⭐⭐☆
对浏览、视频影响不大；对游戏、实时通话重要。专线延迟最低。

### 4. 节点质量 vs 数量 ⭐⭐⭐⭐
58 个节点里可能只有 5 个好用。**看冷门地区节点是否齐全**，这往往反映机场的真实实力。

### 5. 性价比 ⭐⭐⭐⭐
不是越便宜越好。计算方式：`月费 ÷ 实际可用流量 × 稳定性权重`。便宜但经常不能用的，实际成本更高。

### 6. 服务与透明度 ⭐⭐⭐
- 客服响应快不快
- 是否公开线路信息
- 是否有退款政策

## 三、避坑清单

| 🚩 危险信号 | 说明 |
|-------------|------|
| 超低价年付（如 ¥10/年） | 几乎必跑路，回本都难 |
| 夸大宣传"1000G 不限速" | 实际共享带宽，晚高峰形同虚设 |
| 无联系方式、无公告群 | 出问题找不到人 |
| 刚开几天就疯狂推广 | 割韭菜典型套路 |
| 要求提供过多个人信息 | 隐私风险 |
| 订阅链接格式怪异 | 可能是自建的不稳定面板 |

## 五、测试方法（买之前/之后）

### Stage 1：试用阶段
1. 用免费试用或最低档套餐
2. 测三个时段：早上、下午、晚高峰
3. 每个时段测 3 个不同节点

### Stage 2：评估指标
- **延迟**：< 200ms 优秀，> 500ms 较差
- **下载速度**：晚高峰 > 50Mbps 算不错
- **丢包率**：< 3% 为佳
- **可用性**：连续 3 天无故障

### Stage 3：实际场景测试
用你真正要用的服务测试（视频、AI、游戏），而不是只跑测速软件。

---

## 六、心态建议

1. **不要神话任何机场** —— 没有永远稳定的服务
2. **保持备份** —— 至少 2 个机场
3. **短周期为王** —— 用得好再续费长期
4. **关注社区** —— 口碑变化比广告更真实
5. **理性看待排名** —— 别人的体验不一定适合你
