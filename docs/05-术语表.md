# 📚 术语表

> 看懂机场圈的行话，不再一头雾水。

---

## 线路类

| 术语 | 全称 / 英文 | 解释 |
|------|-------------|------|
| **直连** | Direct | 流量直接从你的设备连到境外服务器，简单但容易受网络波动影响 |
| **中转** | Relay | 流量先到国内中转服务器，再转发到境外，带宽更足 |
| **专线** | Dedicated Line | 使用运营商专用线路传输，稳定、低延迟、价格高 |
| **IEPL** | International Ethernet Private Line | 国际以太网专线，稳定灵活，是高端机场的常见配置 |
| **IPLC** | International Private Leased Circuit | 国际专线，最稳定的线路类型之一，常带原生 IP |
| **BGP** | Border Gateway Protocol | 一种智能路由协议，能自动选择最优路径 |
| **家宽 / 住宅 IP** | Residential IP | 家庭宽带出口 IP，比机房 IP 更"干净"，解锁能力强 |
| **原生 IP** | Native IP | 服务器所在地真实注册的 IP（如美国机房配美国 IP），流媒体解锁好 |

## 协议类

| 术语 | 全称 / 英文 | 解释 |
|------|-------------|------|
| **SS / SSR** | Shadowsocks / ShadowsocksR | 老牌轻量协议，兼容性好 |
| **V2Ray / VMess** | V2Ray | 功能强大的代理协议，生态成熟 |
| **Trojan** | Trojan | 伪装成 HTTPS 流量的协议，隐蔽性好 |
| **Hysteria / Hy2** | Hysteria | 基于 QUIC 的新协议，速度快的代表 |
| **sing-box** | sing-box | 新一代代理内核，支持多种协议，性能优秀 |
| **Clash** | Clash | 流行的客户端内核，规则分流能力强 |

---

## 计费类

| 术语 | 解释 |
|------|------|
| **周期性套餐** | 按月/季/年付费，到期需续费 |
| **不限时套餐** | 一次性购买，长期有效（但机场可能跑路） |
| **倍率** | 流量消耗的折算系数。0.5 倍划算，2 倍不划算 |
| **不限速** | 不限制连接速度 |
| **不限设备** | 不限制同时在线的设备数量 |
| **流量结转** | 当月没用完的流量滚存到下个月 |
| **按量计费** | 用多少付多少，不用固定套餐 |

---

## 功能类

| 术语 | 解释 |
|------|------|
| **流媒体解锁** | 节点 IP 能正常访问并解锁 Netflix/Disney+/YouTube 等平台 |
| **Emby / Jellyfin** | 私人影视服务器，一些机场会附赠账号 |
| **AI 可用** | 节点 IP 能正常访问 ChatGPT/Claude/Gemini 等 AI 服务 |
| **落地** | 流量最终从哪个地区出去（如"香港落地"） |
| **负载** | 当前节点上挂了多少用户，负载越高越慢 |
| **测速** | 测试节点的延迟、下载速度、丢包率 |

---

## 客户端类

| 术语 | 解释 |
|------|------|
| **订阅链接** | 机场提供的一串网址，客户端靠它自动获取所有节点 |
| **节点 / 机场** | 一台代理服务器 / 提供代理服务的平台 |
| **系统代理** | 让电脑/手机的全局流量经过客户端 |
| **规则模式** | 智能分流：国内直连，国外走代理 |
| **全局模式** | 所有流量都走代理 |
| **分流规则** | 决定哪些网站走代理、哪些直连的配置 |

## 黑话速查

| 黑话 | 意思 |
|------|------|
| 跑路 | 机场突然关停、消失 |
| 割韭菜 | 用夸张宣传吸引付费后跑路 |
| 白嫖 | 用免费资源 |
| 上车 / 下车 | 购买 / 停止使用某个机场 |
| 翻车 | 机场出问题、不能用 |
| 稳如老狗 | 形容非常稳定 |
| 家宽 | 家庭宽带 IP |
| 落地 IP | 流量出口的 IP 属地 |
