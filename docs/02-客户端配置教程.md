## Windows

### 推荐：Clash Verge Rev

1. 前往 Clash Verge Rev 的 GitHub Release 页面，下载 `Clash.Verge_xxx_x64.msi`（或便携版）
2. 安装并打开
3. 左侧栏点击「**订阅**」
4. 在输入框粘贴你的订阅链接 → 点击「**导入**」
5. 点击「**代理**」，选择一个节点
6. 点击左下角「**系统代理**」开关，变成绿色即生效
7. 打开浏览器测试

**常见问题**：
- 打不开界面？检查是否安装了 WebView2 运行库
- 导入失败？确认订阅链接完整复制，没有多余空格
- 一切正常但没网？试试切换规则模式为「全局」

### 备选：v2rayN

适合习惯传统界面的用户，支持更多协议类型。

## macOS

### 推荐：ClashX Meta / Clash Verge Rev

**ClashX Meta**：
1. 下载 dmg 安装包，拖入应用程序
2. 首次打开需要在「系统设置 → 隐私与安全性」里允许
3. 菜单栏图标 →「配置」→「导入订阅链接」
4. 选择节点 → 菜单栏开启「系统代理」

**Clash Verge Rev**：与 Windows 版操作基本一致。

> 💡 macOS 用户注意：部分软件需要输入开机密码授权安装系统代理。

## Android

### 推荐：Clash Meta for Android / FlClash

1. 从 GitHub 或官方渠道下载 APK 安装
2. 打开应用 → 点击右上角「+」或「配置」
3. 选择「从 URL 导入」→ 粘贴订阅链接
4. 下载配置成功后，进入「代理」页选择节点
5. 点击右下角「播放」按钮建立连接
6. 首次会弹出 VPN 授权请求，点「确定」允许

> 💡 FlClash 界面更现代，对新手更友好。

## iOS

> ⚠️ iOS 上的代理客户端通常需要**非中国大陆区的 Apple ID** 才能下载。

### 推荐：Shadowrocket（小火箭，付费）/ Stash / Loon

以 Shadowrocket 为例：
1. 用非国区 Apple ID 在 App Store 下载 Shadowrocket
2. 打开应用 → 右上角「+」添加配置
3. 类型选「Subscribe」→ URL 填订阅链接 → 完成
4. 回到首页，打开右上角开关连接

### 备选：Karing（有免费额度）

## Linux

### 推荐：Clash Verge Rev / sing-box / v2rayN

1. 下载 AppImage 或对应发行版安装包
2. 命令行启动，或图形界面导入订阅链接
3. 系统代理需要手动设置，或在支持的桌面环境下自动配置

> 💡 命令行用户可使用 `clash` + `yq` 等工具配合订阅链接自动生成配置。

## 路由器

> 路由器配置后，**全家设备无需单独设置**即可使用，是进阶玩法。

### 推荐：OpenClash / PassWall2

**OpenClash**（需路由器刷 OpenWrt 固件）：
1. 在 OpenWrt 的软件包里安装 OpenClash
2. 进入 OpenClash 配置页面 → 「订阅配置」
3. 添加订阅链接 → 更新配置
4. 选择节点，开启代理

**PassWall2**：配置逻辑类似，界面不同。

> ⚠️ 路由器配置有一定门槛，建议先在自己的设备上熟悉客户端后再尝试。

## 通用技巧

### 规则模式 vs 全局模式
- **规则模式**（推荐）：国内网站直连，国外网站走代理，智能分流
- **全局模式**：所有流量都走代理，适合排查问题，但可能拖慢国内访问

### 节点选择
- 优先选延迟低、负载低的节点
- 看视频选支持流媒体解锁的节点
- 晚高峰不稳定可尝试切换节点或线路

### 订阅更新
- 机场节点会变动，建议**定期更新订阅**（多数客户端支持开机自动更新）
- 订阅链接泄露可能导致流量被盗用，不要公开发布
