## 使用原则（先看）

1. **不要只发链接** —— 先给价值，再自然带出仓库
2. **选对版块** —— 发到相关技术/工具社区，别发到无关版块

4. **真诚互动** —— 有人回复要认真回答，别发完就跑
5. **不要刷 Star** —— 绝不买 Star、互 Star、机器人刷

