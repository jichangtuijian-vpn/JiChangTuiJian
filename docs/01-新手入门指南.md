## 一、先搞懂基本概念（2 分钟）

### 什么是"机场"？
"机场"是中文圈对**代理服务**的俗称。它帮你把网络流量通过位于其他地区的服务器转发，从而实现访问某些地区限定的内容、保护隐私等目的。

### 三个核心概念

| 概念 | 通俗解释 |
|------|----------|
| **节点** | 一台位于某地（如香港、日本、美国）的服务器，你的流量从这里"出去" |
| **订阅链接** | 机场给你的一串特殊网址，客户端靠它自动获取所有节点信息 |
| **客户端** | 安装在你设备上的软件，用来连接和管理节点 |

### 工作流程一句话
```
你的设备 → 客户端 → 节点服务器 → 目标网站
```

## 二、选择你的第一个机场

### 新手推荐策略

1. **从"普通系列"或"性价比系列"里选** —— 稳定、风险低
2. **优先选支持月付/短周期的** —— 先测试，别急着买长期
3. **看看是否需要特殊功能**：
   - 看视频/流媒体 → 找标注"解锁 Netflix/Emby"的
   - 用 AI 工具 → 找标注"AI 可用"的
   - 新疆地区 → 找标注"新疆可用"的
   - 多台设备 → 找"不限设备数"的

### 避坑提醒
- ⚠️ 太便宜的年付（如 10 元/年）大概率跑路，别贪便宜
- ⚠️ 免费节点稳定性差，还可能记录你的数据，仅作临时测试用
- ⚠️ 不要只看速度，稳定性和带宽更重要

## 三、注册与购买

以大多数机场的流程为例：

1. 从主仓库表格点击进入机场官网（注意：**认准表格里的链接，避免进仿冒站**）
2. 注册账号（邮箱验证）
3. 选择套餐 → 支付（常见支持支付宝/微信/USDT）
4. 支付后在"用户中心"找到**订阅链接**（通常是一串很长的网址）

> 💡 有些机场还提供更友好的"客户端导入"方式，可以直接扫码或一键导入。

## 四、配置客户端（以 Clash Verge Rev 为例）

详细配置见 [客户端配置教程](02-客户端配置教程.md)，这里给最快路径：

1. **下载安装**：到 Clash Verge Rev 的 GitHub 页面下载对应系统版本
2. **打开软件** → 左侧「订阅」标签
3. **粘贴订阅链接** → 点击「导入」
4. **更新配置**：导入后点一下更新，让软件拉取节点列表
5. **选择节点**：在「代理」标签选一个节点（新手可先选延迟低的）
6. **开启系统代理**：在「设置」里打开「系统代理」开关
7. **测试**：浏览器打开 Google 或 ipinfo.io 验证

## 五、常见误区

| 误区 | 正确做法 |
|------|----------|
| "节点越多越好" | 节点质量比数量重要，稳定带宽是关键 |
| "协议越新越好" | 中转机场里，机器稳定性比协议更关键 |
| "买了就能一直用" | 机场可能跑路，务必准备备用 |
| "速度越快越安全" | 速度和隐私是两回事 |
| "免费的最香" | 免费服务往往用你的数据换成本 |
